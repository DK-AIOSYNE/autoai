[Voyant moteur allumé]
Un voyant moteur peut être lié à la vanne EGR, au FAP ou à un problème de combustion.

> Questions à poser :
1. Le voyant moteur est-il fixe ou clignotant ?
   - Fixe → Souvent lié à un encrassement (FAP ou EGR). → Étape suivante.
   - Clignotant → Risque de ratés moteur graves. → Arrêt immédiat + RDV. 

2. Le voyant FAP est-il aussi allumé ?
   - Oui → Probable saturation du FAP → Conseiller nettoyage.
   - Non → Vérifier symptômes (perte de puissance, fumée noire, consommation élevée).
       - Oui → Probable vanne EGR encrassée. → RDV conseillé.
       - Non → Cause incertaine → Diagnostic électronique.

👉 Conclusion : Dans tous les cas, proposer "Trouver un garage partenaire".


[Voyant FAP]
Quand le voyant FAP s’allume, cela indique une saturation du filtre. Un nettoyage est souvent suffisant.

> Questions à poser :
1. Le voyant vient-il de s’allumer ?
   - Oui → Possible de rouler un peu, mais nettoyage conseillé rapidement.
   - Non (voyant présent depuis plusieurs trajets) → Risque d’endommager le moteur → Nettoyage urgent.

2. Y a-t-il perte de puissance ?
   - Oui → Saturation avancée → RDV nécessaire.
   - Non → Nettoyage recommandé pour éviter aggravation.

👉 Conclusion : Proposer "Trouver un garage partenaire".


[EGR encrassée]
Une vanne EGR encrassée peut provoquer des ratés moteur, une perte de puissance et une surconsommation. 

> Questions à poser :
1. Voyez-vous de la fumée noire ?
   - Oui → Encrassement confirmé → RDV conseillé.
   - Non → Peut venir du FAP ou d’un capteur → Diagnostic recommandé.

2. Le voyant moteur est-il aussi allumé ?
   - Oui → Diagnostic obligatoire.
   - Non → Si perte de puissance → Nettoyage conseillé.

👉 Conclusion : Proposer "Trouver un garage partenaire".


[AdBlue]
Le système AdBlue réduit les NOx. S’il est vide, un message d’alerte apparaît et le véhicule peut refuser de démarrer.

> Questions à poser :
1. Avez-vous vu un message "Niveau AdBlue bas" ou "impossible de redémarrer bientôt" ?
   - Oui → Remplir le réservoir AdBlue dès que possible.
   - Non → Vérifier si le voyant moteur est aussi allumé.
       - Si oui → Autre cause possible (EGR/FAP).

2. Le véhicule refuse-t-il de démarrer ?
   - Oui → Réservoir vide → Faire un appoint immédiatement.
   - Non → Simple alerte → Prévoir appoint avant blocage.

👉 Conclusion : si le problème persiste après appoint → Proposer "Trouver un garage partenaire".
